# Iris Quiambao — Portfolio Website Specification

## 1. Project Overview

Create a modern, editorial-style personal portfolio website for **Iris Quiambao**, a designer specializing in UI design, web design, graphic design, photo/video editing, multimedia, and creative content creation.

The website should feel:

- Elegant
- Editorial
- Minimal
- Creative
- Modern
- Refined
- Visually intentional
- Premium but approachable

The design should combine the feel of a **designer portfolio, digital magazine, and creative studio website**.

Do not make the website look like a generic developer portfolio or standard SaaS template.

# 21. ANIMATION DIRECTION

Use subtle editorial animations.

### Recommended

- Fade-up text
- Slow image reveal
- Image scale on scroll
- Text reveal
- Parallax image movement
- Hover image scaling
- Underline animations
- Smooth section transitions

### Avoid

- Excessive bouncing
- Large spinning animations
- Generic loading animations
- Excessive 3D effects
- Overly flashy gradients
- Excessive glassmorphism

Animation should enhance the portfolio rather than distract from the work.

# 26. DESIGN PRINCIPLES

The implementation should follow these rules:

### 1. Typography is the hero

Large serif typography should be one of the primary visual elements.

### 2. Let the work breathe

Use generous spacing around project imagery.

### 3. Keep the palette controlled

Do not introduce unrelated colors.

Primary palette:

```text
#e9e8ff
#1b1a55
#9290c3
#070f2b
#ffffff
```

Supporting project colors can be introduced where appropriate.

### 4. Editorial composition

Avoid uniform card grids everywhere.

Use varied compositions.

### 5. Minimal UI

Buttons, navigation, and controls should be understated.

### 6. Strong section transitions

Each portfolio phase should feel like entering a new chapter.

### 7. Image-first storytelling

The actual design work should receive more visual attention than explanatory text.
